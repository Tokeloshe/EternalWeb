Name what you keep by what it is, not where it lives.

A URL names a place, and places change. EternalWeb archives pages by a fingerprint of their content: an address that can only ever mean those exact bytes, signed by whoever kept them.

The addresses, signatures, reputation and curation scores in the film are computed by eternalweb-core (cargo run -p eternalweb-core --release --example film). The network act is the roadmap design and is labelled as such.

01Link rot

A link is a promise that something will be at a place. Pages get edited, moved, quietly trimmed, or taken down, and the URL keeps pointing at whatever is there now, or at nothing. The record of what the page said is the first thing lost.

02An address made of the content

EternalWeb hashes the bytes of what it archives with BLAKE3 and wraps the result as a CIDv1 content identifier. The address of the March version of the page in the film is:

{{CID}}

Change one character, 4.82 m to 4.83 m, and almost every character of the address changes. Checking works the other way round: verify_integrity(address, bytes) recomputes the fingerprint, so the original bytes match and edited bytes are rejected. Anyone holding a copy can prove it is the copy.

03Signed by whoever kept it

An archivist signs the address with an Ed25519 key. The signature verifies for that address and fails for any other, including the edited page's. Trust attaches to people and their keys, not to whichever server happens to answer.

04A removal is a new version

When the page changes, the new content gets a new address and joins the feed as a new version. The old version keeps its own address. Taking the data off the county's site doesn't touch the March archive: its address still returns the March readings, byte for byte.

05Every reader a keeper (the design)

The design is a peer-to-peer network where archives replicate across the nodes of the people who read them, so no single server decides what survives, and a request for an address is answered by the nearest peer that holds it. This is not built yet. The networking layer (libp2p replication, discovery, mesh) is scaffolded but stubbed; today an archive lives in the local store of the node that made it.

06Reputation, not tokens

Archiving, hosting, curating and development earn reputation points, with levels from Newcomer through Contributor, Guardian and Sentinel to Eternal. Community curation scores each archive as upvotes over all votes, with flags tracked separately. There's no speculative coin.

08Try it

$ git clone https://github.com/Tokeloshe/EternalWeb.git && cd EternalWeb
$ cargo build --release
$ ./target/release/eternalweb archive https://example.com --public
$ cargo run -p eternalweb-core --release --example film     # the scenario in the film

09Help build it
